<b>MasterClass Combined Python Project</b>

Overview

This project is a Python console application that demonstrates multiple fundamental programming concepts combined into a single project. It allows users to create, save, and view a user profile using a menu-driven interface.

The project integrates the following programming concepts:

Object-Oriented Programming (OOP)

Functions

File Handling (JSON)

Loops

Exception Handling

The program stores user profile information in a JSON file so it can be retrieved later.

Features
1. Create User Profile

Users can enter:

Name

Age

Email

The program then:

Creates a user object

Displays the profile

Saves the profile to a JSON file

2. View Saved Profile

The program loads the previously saved user profile from a JSON file and displays it.

3. Menu Driven System

The program runs inside a loop providing a menu with options:

Create User Profile

View Saved Profile

Exit
